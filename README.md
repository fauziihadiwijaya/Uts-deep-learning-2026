# UTS Deep Learning 2026
### Hands-on Deep Learning: Classification, Regression, and Clustering

## Overview

This repository contains the group project for the **Deep Learning course — Midterm Examination (UTS) 2026**.

The project focuses on implementing and evaluating deep learning approaches across three fundamental machine learning tasks: classification, regression, and clustering. Each task involves data exploration, preprocessing, model development, experimentation, and performance evaluation.

The main objective is to understand how deep learning techniques can be applied to different types of data and problems, while analyzing model performance through appropriate evaluation metrics.

## Project Scope

This project consists of three main tasks:

### 1. Classification

Developing deep learning models to classify data into predefined categories. The task explores classification approaches, model performance, and the use of different input modalities.

### 2. Regression

Developing deep learning models to predict the Remaining Useful Life (RUL) of machines based on historical operational and sensor data. The task includes sequence modeling, model comparison, and prediction evaluation.

### 3. Clustering

Applying deep learning approaches to discover patterns and group unlabeled data into meaningful clusters. The task explores data representation, clustering methods, and cluster evaluation.

## Project Workflow

The general workflow for each task consists of:

1. **Data Understanding** — Exploring dataset characteristics and understanding the problem.
2. **Data Preprocessing** — Preparing data through cleaning, transformation, and normalization.
3. **Model Development** — Designing and implementing suitable deep learning architectures.
4. **Model Training** — Training models and conducting experiments.
5. **Model Evaluation** — Assessing model performance using appropriate evaluation metrics.
6. **Result Analysis** — Interpreting experimental results and comparing model performance.

## Technologies & Tools

The project uses the following tools and technologies:

- **Programming Language:** Python
- **Deep Learning Framework:** PyTorch / TensorFlow
- **Data Processing:** Pandas, NumPy, Scikit-learn
- **Data Visualization:** Matplotlib, Seaborn
- **Development Environment:** Google Colab / Jupyter Notebook
- **Version Control:** Git & GitHub
